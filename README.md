# Next App Router modifier

This independently authored MIT content replaces the React Router SPA with a Next App Router application. It preserves the reusable React data/schema, item models and UI component bytes. This is a separate modifier, not a React setting, enrolled native root, installed composition or fallback runtime.

The backend contract is bounded cancellable JSON CRUD against an explicitly configured server-only HTTP endpoint. No database, credentials or authentication service is bundled. Missing backend configuration produces an unavailable result; an empty successful collection is never invented. Server pages/routes are separate from interactive client forms. Next/server-only16.3.8/0.0.1 and React19.3.0 use the genuine Bun1.4.2 lock, unchanged after one offline frozen producer check.

The source delivery has two stages. Content and raw payloads are captured first. After actual React and Next content publication, authenticated immutable source subjects bind modifier.manifest.json through the existing closed Modifier schema. That final file is intentionally absent while publication subjects are unavailable; no zero/dummy source pins or caller authority are emitted. See docs/lifecycle.md. Pure parser/render checks cannot certify conversion, update, reversal, native Bun execution or full P13.
