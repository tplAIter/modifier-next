# Authoring boundary

Keep public MIT content and exact publisher-provided source/lock subjects. Do not import private templates/history or read credential configuration. Bun is the package manager; use its genuine frozen lock. No source edit grants package acquisition, lifecycle scripts, enrollment, formatter execution, tool authority or installed modifier composition. Preserve LICENSE and .github/CODEOWNERS.

Use the actual tplaiter manifest/export/block/modifier parsers and core renderer/generator APIs. Preserve retained wire identifiers. Keep server-only backend configuration out of client imports/props; client props must be serializable typed models. Never introduce a template-as-native-root or handcrafted composition writer. Qualified author checks and actual installed lifecycle acceptance are distinct.
